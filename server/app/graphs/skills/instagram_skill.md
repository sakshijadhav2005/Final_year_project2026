## 4. Strict Copywriting Rules (Do's & Don'ts)

### ✅ DO:
- Use clean line breaks and emojis as visual anchors (✨, 🚀, 💡, ⚡, 📌).
- Include suggested carousel slide visual descriptions so designers/creators know what graphics to build.
- Encourage saves (`💾 Save`) and shares (`🚀 Share`).

### ❌ NEVER DO:
- **NEVER** write a single wall of text without line breaks.
- **NEVER** use boring corporate jargon without translating it to engaging language.
- **NEVER** overload with 30 irrelevant generic hashtags.
