# Persona & Agent Skill Specifications (Member 3)

Each file here defines the persona, tone, style rules, formatting blueprints, and negative constraints for an autonomous creator agent.

## Skill Files:
- `linkedin_skill.md`: Instructions for viral LinkedIn thought-leadership copy.
- `instagram_skill.md`: Instructions for carousel slides and caption formatting.
- `newsletter_skill.md`: Instructions for clean, readable email broadcasts.
- `blog_skill.md`: Instructions for structured long-form technical blogs.
- `summary_skill.md`: Instructions for C-level executive bullet briefs.
- `flyer_skill.md`: Instructions for snappy marketing recap flyers.

Agents automatically load these files at runtime via `BaseCreatorAgent._load_skill()`.
