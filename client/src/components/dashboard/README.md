# Dashboard & Catalog Components (Member 1)

This folder contains components for the Organizer and Attendee dashboards and event catalog cards.

## Components:
- `CatalogNav.tsx`: Navigation bar for switching between catalogs (`all`, `meetup`, `event`, `speech`, `session`).
- `EventCard.tsx`: Event card with category badges, date, organizer name, and links to the Event Detail Hub (`/events/:id`).
- `DashboardUploadCard.tsx`: Fast upload interface for organizers with format and language selector.
- `CreatePostForm.tsx`: Community post and reflection creator modal.
